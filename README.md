# 🤖 Smart College Campus Assistant

A **multi-agent AI-based college event planning assistant** built using **CrewAI and the Nexus API**. The system accepts a natural-language campus event request and uses multiple specialised AI agents to collaboratively generate a complete event plan.

## 📌 Project Overview

The Smart College Campus Assistant is designed to simplify the planning and coordination of college events involving students, faculty, guests, and external participants.

The system uses a **sequential multi-agent workflow**, where each agent performs a specific responsibility and passes its output to the next agent.

### Main Capabilities

- 🗓️ Event schedule planning
- 👥 Guest and participant coordination
- 📋 Event logistics planning
- 📢 Communication and announcement preparation
- 💰 Event budget estimation
- 🏢 Venue capacity checking
- 🌤️ Weather information lookup
- 🚗 Guest transportation estimation
- 🤖 AI-powered event planning using Nexus API

---

## 🏗️ System Architecture

The project uses three specialised AI agents:

### 1. Event Planner
Responsible for understanding the event request and preparing the overall event structure, schedule, and activities.

### 2. Operations Coordinator
Handles practical event requirements such as venue capacity, transportation, budget, duration, and other logistics.

### 3. Communication Coordinator
Prepares announcements, coordination instructions, and communication content based on the event plan.

The agents work sequentially, allowing later agents to use the information generated by earlier agents.

```text
                User Request
                     │
                     ▼
             ┌─────────────────┐
             │  Event Planner  │
             └────────┬────────┘
                      │
                      ▼
          ┌────────────────────────┐
          │ Operations Coordinator │
          └────────────┬───────────┘
                       │
                       ▼
          ┌─────────────────────────┐
          │ Communication Coordinator│
          └────────────┬────────────┘
                       │
                       ▼
                Final Event Plan
```

## 🔧 Custom Tools

The project implements multiple tools to support the agents:

| Tool | Purpose |
|---|---|
| `calculate_event_duration` | Calculates event duration |
| `estimate_event_budget` | Estimates event expenses |
| `check_venue_capacity` | Checks whether a venue can accommodate participants |
| `get_event_weather` | Retrieves weather information using Open-Meteo |
| `calculate_guest_transport` | Estimates guest transportation requirements |
| `nexus_llm_tool` | Performs LLM-based processing using Nexus API |

The tools are integrated into the agent workflow and used during event planning.

---

## 🔗 External API Integration

The project uses the **Open-Meteo API** to retrieve weather information for event planning.

Open-Meteo is a free weather API that can be accessed without an API key.

The weather information obtained from the API can be incorporated into the final event plan.

The project also uses the **Nexus API for all LLM calls**, as required by the assignment.

## ⚙️ Workflow

The application follows this workflow:

1. User enters a campus event request.
2. The Event Planner analyses the request.
3. Event planning information is passed to the Operations Coordinator.
4. The Operations Coordinator performs required calculations and API lookups.
5. The Communication Coordinator uses the previous outputs to prepare communication content.
6. The agents combine their results.
7. A final event plan is generated for the user.

## ▶️ How to Run

### 1. Open the Notebook

Open the `.ipynb` file using **Google Colab**.

### 2. Install Dependencies

Run the installation cell in the notebook.

### 3. Configure Nexus API

Add your Nexus API key to Google Colab Secrets using:

```text
NEXUS_API_KEY
```

### 4. Run the Notebook

Execute the cells from top to bottom.

### 5. Enter an Event Request

When prompted, enter a request such as:

```text
Plan a one-day inter-college technical fest for 400 participants.
Include a hackathon, paper presentation and robo race.
```

The agents will process the request and generate the final event plan.
